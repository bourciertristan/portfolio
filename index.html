10/07/2026 · IT-Connect

Une attaque sur Microsoft 365 par « code d'appareil » : la victime saisit un code sur la vraie page Microsoft et autorise l'attaquant sans le savoir. Le MFA ne bloque rien dans ce cas.

Voir l'article

Ce que j'en retiens

Un mot de passe seul ne suffit pas, et le MFA aide mais n'arrête pas toutes les attaques. Après une attaque, il faut aussi fermer les sessions, pas seulement changer le mot de passe.
